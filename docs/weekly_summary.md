# 주간 건강 리포트 기능 문서

## 1. 문서 목적

이 문서는 HealthLog 프로젝트의 주간 건강 리포트(Weekly Summary) 기능의 구현 기준을 정리한다.
CSV에 저장된 식단(섭취)·운동(소모) 기록과 할 일 기록을 주 단위(일~토)로 집계하고, 그 결과를 요약 화면으로 보여주는 것을 목적으로 한다.

> 참고: 이 문서는 구현 전 명세 초안이다. 메인 화면과의 날짜 연동 방식과 할 일 데이터 형식은 팀의 공통 설계와 확인한 뒤 확정한다.

## 2. 기능 범위 및 주요 할 일

- **주간 집계**: 기준 날짜가 속한 주(일요일~토요일)의 기록만 골라 집계
- **칼로리 요약**: 총 섭취(intake), 총 소모(burn), 순 칼로리(섭취 - 소모) 계산
- **할 일 요약**: 해당 주의 전체 할 일 수, 완료 수, 완료율 계산
- **요약 화면 표시**: 칼로리 요약과 할 일 요약을 한 화면에 함께 출력
- **리포트 버튼**: 메인 화면에서 주간 리포트 창을 여는 버튼 제공

## 3. 데이터 및 연동 기준

### 3.1 입력 데이터 (CSV)

**칼로리 기록**

| 컬럼 | 설명 | 예시 |
|---|---|---|
| id | 기록 번호 | 1 |
| date | 날짜 (YYYY-MM-DD) | 2026-10-12 |
| type | 기록 종류 (`intake`: 섭취, `burn`: 소모) | intake |
| name | 기록 이름 | 아침 샐러드 |
| kcal | 칼로리 (정수) | 350 |

**할 일 기록** (협의 필요: 실제 형식 확정 후 수정)

| 컬럼 | 설명 | 예시 |
|---|---|---|
| id | 할 일 번호 | 1 |
| date | 날짜 (YYYY-MM-DD) | 2026-10-12 |
| title | 할 일 내용 | 스쿼트 20회 |
| done | 완료 여부 | true |

- 파일 인코딩은 UTF-8(BOM 허용)을 기준으로 한다.

### 3.2 주 구간 계산 기준

- 한 주는 **일요일부터 토요일까지**로 한다.
- 기준 날짜가 속한 주의 일요일을 시작일, 토요일을 종료일로 계산한다.
- 같은 주 안의 **어느 날짜를 기준으로 선택해도 동일한 결과**가 나온다.
- 범위 밖 기록은 집계에서 제외한다.

### 3.3 메인 화면 연동 (협의 필요)

- 메인 화면에서 선택된 날짜(`selected_date`)를 기준 날짜로 전달받는 것을 목표로 한다.
- 현재 첫 동작 코드는 기준 날짜를 코드 내 고정값으로 사용하며, 파이프라인 연동은 이후 단계에서 적용한다.

## 4. 집계 규칙

| 항목 | 계산 방식 |
|---|---|
| 총 섭취 | 해당 주 `intake` 기록의 kcal 합계 |
| 총 소모 | 해당 주 `burn` 기록의 kcal 합계 |
| 순 칼로리 | 총 섭취 - 총 소모 |
| 할 일 전체 | 해당 주 할 일 기록 수 |
| 할 일 완료 | 해당 주 `done`이 참인 기록 수 |
| 완료율 | 완료 수 / 전체 수 × 100 (전체 0건이면 0%) |

## 5. 입력값 및 예외 처리 규칙

| 항목 | 검증 및 처리 규칙 |
|---|---|
| 칼로리 CSV 없음 | 오류 안내창을 표시하고 리포트를 열지 않음 |
| 할 일 CSV 없음 | 칼로리 요약은 정상 표시, 할 일 요약은 "데이터를 불러오지 못했습니다"로 안내 |
| 해당 주 기록 없음 | 섭취·소모를 0으로, 할 일은 0건(0%)으로 표시 |
| 날짜·숫자 형식 오류 | 해당 행을 건너뛰고 로그 출력 |
| 알 수 없는 type | 집계에서 제외 |

## 6. 완료 조건 (Acceptance Criteria)

- [ ] "주간 리포트" 버튼을 누르면 요약 창이 열린다.
- [ ] 한 주가 일요일~토요일 기준으로 계산된다.
- [ ] 같은 주 안의 어느 날짜를 기준으로 해도 같은 결과가 나온다.
- [ ] 칼로리 요약(총 섭취, 총 소모, 순 칼로리)이 정확히 표시된다.
- [ ] 할 일 요약(전체, 완료, 완료율)이 함께 표시된다.
- [ ] 다른 주의 기록은 집계에서 제외된다.
- [ ] CSV 파일이 없거나 기록이 없어도 프로그램이 종료되지 않는다.
- [ ] 문서가 `docs/weekly_summary.md` 경로에 저장되어 있다.
