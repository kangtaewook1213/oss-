## 3. 논의 내용과 결정 사항

**새 디자인 1단계: 단일 창 구조 적용**

현재는 날짜를 선택할 때마다 상세 창과 기능 창이 별도로 열려 창이 여러 개 쌓이고, 화면마다 디자인이 일관되지 않는 문제가 있음. 이를 개선하기 위해 왼쪽 메뉴가 있는 단일 창 구조로 변경하기로 결정함.

- `main.py`를 왼쪽 메뉴와 화면 전환 기능을 갖춘 `App` 구조로 변경
- `ui.py`를 추가하여 색상, 글꼴, 카드, 차트 등 공통 UI 요소와 여러 화면에서 사용하는 함수를 관리
- `home.py`를 추가하여 달력과 선택한 날짜의 요약 정보를 보여주는 홈 화면 구성
- 할 일, 칼로리, 인바디, 주간 리포트 화면은 각 담당자가 별도 파일로 옮기기 전까지 `home.py`에 임시로 배치
- `python main.py` 실행 시 하나의 창에서 홈, 할 일, 칼로리, 인바디, 주간 리포트 화면을 전환할 수 있도록 구성
- 기존 기능인 할 일 추가·완료·삭제·수정, 칼로리 추가·수정·삭제, 인바디 저장, 주간 리포트 주 이동 기능을 그대로 유지
- `data/` 폴더의 CSV 파일 형식은 변경하지 않음
- 다른 팀원의 기존 기능 파일인 `daily_todo.py`, `calorie_diary.py`, `body_tracker.py`, `weekly_summary.py`는 수정하지 않음
